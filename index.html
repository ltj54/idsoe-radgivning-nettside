IDSØE RÅDGIVNING

Barn og elever med stort læringspotensial

Ella Idsøe holder kurs og seminarer og gir rådgivning til foreldre, lærere og fagmiljøer om læringsbehov, tilpasset undervisning og inkludering.

Utgangspunktet er barnets behov

Stort læringspotensial er ikke alltid synlig i karakterene. Passende utfordringer, sosial tilhørighet og barnets egen stemme er viktige utgangspunkt for å forstå hva som trengs.

FAGLIG FORMIDLING

Kurs og seminarer med Ella Idsøe

Om stort læringspotensial, tilpasset undervisning og inkludering.

Ella holder kurs og seminarer for foreldre, lærere og andre fagpersoner som ønsker mer kunnskap om barn og elever med stort læringspotensial.

For en konkret samling avklares tema, målgruppe og gjennomføring i dialog med Ella.

En henvendelse kan gjerne beskrive hvem samlingen er for, hvilke spørsmål dere ønsker å belyse, og ønsket tidspunkt.

Kontakt om kurs eller seminar

Fagområder

  • Stort læringspotensial og ulike læringsbehov
  • Differensiering og tilpasset undervisning
  • Motivasjon og faglig progresjon
  • Inkludering, tilhørighet og elevmedvirkning

Innholdet i det enkelte kurset eller seminaret avtales med Ella.

Hvem kan kursene tilpasses for?

Innhold og arbeidsform kan tilpasses skoleledere, lærere i grunnskolen, ansatte i barnehagen, PPT og andre fagmiljøer. Målgruppe, problemstilling og rammer avklares med Ella før gjennomføring.

MÅLGRUPPER

Informasjon for deg som møter barnet

For foreldre

Barnets behov hjemme og på skolen. Nysgjerrighet, trivsel og samarbeid med læreren.

For lærere og skolemiljøer

Kartlegging, passende utfordringer og inkludering i undervisningen.

For leger og psykologer

Læringspotensial, skoleerfaringer og barnets styrker og vansker sett i sammenheng.
